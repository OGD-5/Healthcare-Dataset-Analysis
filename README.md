# Healthcare Operations & Financial Intelligence
### AnalystLab Africa Experience Lab Internship | Week 3

## Project Overview

This project focused on analysing hospital operations, financial information, and patient flow to support better understanding of healthcare facility performance.

The objective was to work with multiple healthcare datasets, assess their quality, prepare them for analysis, and develop an executive-facing dashboard.

## Tools Used

- MySQL
- SQL
- Power Query
- Power BI

## Project Workflow

1. **Business Problem Definition:** Established the operational and financial questions guiding the investigation.
2. **Database Development:** Created a relational database in MySQL and imported the available datasets.
3. **Data Assessment:** Reviewed data structure, completeness, and quality.
4. **Data Preparation:** Used Power Query to clean and transform the datasets while preserving relevant records.
5. **Data Analysis:** Applied SQL to investigate hospital operations, cost patterns, and patient flow.
6. **Dashboard Development:** Built an interactive Power BI dashboard to present the analysis.

## Key Learning Outcomes

- Relational database creation and management.
- SQL-based data exploration.
- Data quality assessment and handling missing values.
- Data transformation with Power Query.
- Data modelling and visualisation with Power BI.
- Applying analytical thinking to healthcare business problems.
